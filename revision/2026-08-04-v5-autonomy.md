# v5.0.0: tiered autonomy + self-verify + memory + DESIGN.md (selective ECC/awesome-design-md adoption)

## Summary

Evolves the platform toward autonomous "idea → code → deploy → monitor" without suspending safety. Adds 3 skills (`/autopilot`, `/memory`, `/design-md`), enriches existing agents with a self-verify loop, role memory, and observability feedback. Selectively adopts ECC patterns (plan→test→implement→review→verify→remember→improve, instincts, AgentShield) — does NOT fork ECC's 67 agents. Integrates awesome-design-md's DESIGN.md concept for UI fidelity.

## Decisions (user-confirmed)

| Decision          | Choice                                                                                             |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| Autonomy strategy | **Tiered** (L0 human / L1 semi / L2 staging-auto+rollback / L3 sandbox-full), not blanket autonomy |
| ECC integration   | **Selective adoption** of patterns into the 20 seats; no fork of ECC's 67 agents                   |
| DESIGN.md         | **New `/design-md` skill** + ui-ux/frontend read DESIGN.md as design source                        |

## New skills (3)

- `/autopilot` — tiered autonomous SDLC; wraps `/design` with a per-tier STOP policy; RULE 4/7/8/10 never suspended by any tier
- `/memory` — role-scoped lessons ledger (`team/communications/memory/<role>/`); agents read at startup, append after non-trivial work (append-only, RULE 6; zero business knowledge)
- `/design-md` — adopt a DESIGN.md (pick from awesome-design-md or generate); ui-ux-designer owns `design/uiux/DESIGN.md`; frontend implements against it

## Agent enrichments

- `/design`: autopilot mode (per-tier STOP policy)
- build roles (frontend/backend/…): self-verify capability (build→self-test→self-review→verify before handoff); role memory at startup; frontend reads DESIGN.md
- ui-ux-designer: DESIGN.md ownership (design source of truth; design-system.md derived)
- bi-analyst + ops: observability feedback (post-deploy monitor → regression auto-creates issue for manager — closes the loop)
- security: AgentShield-style scanning (prompts/hooks/MCP/permissions/secrets/agent files)
- manager: reads role memory; quality gate enforces self-verify + memory-append; `/autopilot` awareness + tiered STOP

## Safety guarantees (unchanged, never suspended by autonomy)

RULE 4 (L3 risk human), RULE 7 (no push main), RULE 8 (K8s in gitops), RULE 10 (prod SQL human), RULE 5.4 (no creds). Tier gates workflow STOPs, not individual-action risk tiers.
